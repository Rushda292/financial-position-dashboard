Financial Position Dashboard
📊 Project Overview

This project is an interactive Financial Position Dashboard created using Power BI. It provides a clear overview of an organization's financial performance, including Assets, Equity, Liabilities, and overall financial position.

📌 Key Features
💰 Total Amount: 2M
📈 Total Assets: 882K
🏦 Total Equity: 485K
📄 Total Liabilities: 397K
✅ Balance Check Indicator
📊 Financial Items by Category Analysis
🍩 Financial Position by Category
📅 Financial Amount by Year
🎛️ Interactive Category and Year Slicers
🔄 Reset Slicer Option
🛠️ Tools Used
Power BI
DAX
Data Visualization
Financial Analysis

📊 Dashboard Insights

The dashboard helps users analyze:

Financial distribution across Assets, Equity, and Liabilities.
Total financial amounts and balance status.
Financial items such as Capital, Accounts Payable, Inventory, and Retained Profits.
Year-wise comparison of financial categories.
Overall financial position through interactive visualizations.

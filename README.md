# 📊 Financial Position Dashboard

An interactive **Financial Position Dashboard** created using **Power BI** to analyze and visualize an organization's financial performance.

---

## 📌 Project Overview

The Financial Position Dashboard provides a clear and interactive overview of key financial metrics, including:

- 💰 Total Amount
- 📈 Total Assets
- 🏦 Total Equity
- 📄 Total Liabilities
- ✅ Balance Check

The dashboard helps users understand the overall financial position through interactive charts, KPI cards, slicers, and financial category analysis.

## 📈 Dashboard Features

### 🔹 KPI Cards

The dashboard displays important financial KPIs:

- Total Amount
- Total Assets
- Total Equity
- Total Liabilities
- Balance Check

### 🔹 Financial Items by Category

A horizontal bar chart is used to analyze financial items based on:

- Assets
- Equity
- Liabilities

Some financial items included are:

- Due From Operating Segments
- Capital
- Accounts Payable
- Cash and Equivalents
- Retained Profits / Accumulated Losses
- Property, Plant and Equipment
- Prepaid Expenses
- Inventory
- Trade Receivables
- Borrowings

### 🔹 Financial Position by Category

A donut chart visualizes the distribution of:

- Assets
- Equity
- Liabilities

### 🔹 Financial Amount by Year

A bar chart compares financial categories across different years.

### 🔹 Interactive Slicers

Users can filter the dashboard using:

- Category Filter
- Year Filter

### 🔹 Reset Slicer

A reset option is included to quickly clear applied filters.
